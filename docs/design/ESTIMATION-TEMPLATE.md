# 工時估算方法 — AgentCraft（代理工坊）

> 方法依據：複雜度分級 + 風險緩衝係數（見 eason-skills `docs/decisions/ADR-001-effort-estimation-method.md`）。
> 本檔是「怎麼估」的規則手冊，實際估算結果與評估依據填在 `docs/design/TASK.md` 對應 Layer 的「工時估算」表與「評估依據」。

## 複雜度分級標準

| 級別 | 基準工時 | 判斷依據 |
| ---- | -------- | -------- |
| S    | 0.5 天   | 單一函式 / 單一端點，無外部依賴，邏輯直線 |
| M    | 1–1.5 天 | 涉及 2-3 個檔案協作，或 1 個外部依賴但已有校準範例可循 |
| L    | 2–3 天   | 涉及新模組、新 Schema，或首次串接的外部服務 |
| XL   | 3–5 天   | 跨多個 Layer 的架構性變更，或高不確定性的整合 |

## 風險緩衝係數

- 標準緩衝：+20%（涵蓋 debug、code review、環境問題等已知會被低估的時間）
- 首次串接外部服務：+30–50%（疊加在標準緩衝之上，不取代）
