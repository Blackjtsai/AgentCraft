三步學會指揮 AI

不需要程式背景。所有企業資料與操作都是教學模擬。

① 交代任務

用一般說話的方式，請 AI Agent 查詢各系統、處理企業案件。

② 確認方案

Agent 先提出方案，你同意後它才動手。按同意不代表對方已答應。

③ 寫成 Skill

把處理方法寫成 Skill，換新案件驗證能不能重複使用。

Agent 的界線

可以直接做查資料、比較選項、整理方案與報告
要你先同意聯絡真人、寫入系統、發通知
要先停下來查身分未核對、資料矛盾、結果不明
要交給負責單位需要專業判斷或超出權限

常見問題

Agent 做很久怎麼辦？

畫面會顯示目前步驟與已經過的時間。你可以先看左邊的任務清單，也可以按「停止」。

按「同意」是什麼意思？

只代表 Agent 可以照方案去做，不代表病患、客戶或主管已經答應。

做錯了會扣分嗎？

不計分。被擋下的操作是學習提示。

可以重來嗎？

第一關可以「重設本案」，案件資料回到初始，Skill 與學習紀錄保留。

登入連結沒收到？

約 1–2 分鐘內會寄達，請先檢查垃圾郵件匣；連結 10 分鐘內有效且只能用一次。
