醫療業情境實作

選一個任務，用 Agent 完成案件，再把處理方法整理成 Skill。

跨系統協調約 3–6 小時第一關進行中

情境 1・門診異動的跨系統協調

你是門診行政協調人員。A 醫師請假，3 位病患的門診受影響，指揮 Agent 聯絡他們，依院內規則改掛、通知或交接。

練習重點
  • 先查清楚現有安排：代診照常看的病患，不必取消重掛
  • 「想看原醫師」只是偏好，病患答應具體場次才能改掛
  • 病患問能不能延後回診時，不替醫師判斷，依規則交接
繼續實作
跨單位協調約 3–6 小時尚未開始

情境 2・出院準備的跨單位協調

你是出院準備協調人員。林女士明天出院，指揮 Agent 協調返家接送、指定輔具與居家服務 3 項安排。

練習重點
  • 比對照顧計畫與各項服務的時間，找出還沒接上的地方
  • 分清楚誰能確認什麼：病患、家屬、專業人員
開始實作
