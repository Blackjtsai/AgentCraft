## 關鍵業務約束

- Agent 只能使用情境包指定的 tool，只碰 Digital Twin 的模擬系統
- 完成判定看模擬系統實際結果，不看 Agent 說了什麼
- 方案經學員確認前，不得對模擬系統做寫入
- 情境包不自帶資料，只引用 Twin 內的資料；劇本提到的資料必須在 Twin 找得到
- Agent 執行位置待 ADR-001
